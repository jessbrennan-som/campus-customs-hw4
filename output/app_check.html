Campus Customs: App Check

Three screenshots from the running Campus Customs website, taken with a throwaway copy of the database so no real customer data was used. Handsome Dan is the shop's chatbot.

Check 1: Chat checks inventory and price

Screenshot 1: Handsome Dan answers a stock and price question

What this proves: The chatbot answers from the live database, not from memory: it quotes the exact price ($68.00) and the exact stock in the shopper's size (5 left in M), which the shop checks against what its tools returned. It also shows the chat understands "this hoodie" from the page the shopper is on.

Check 2: Dynamic search result cards from the chat

Screenshot 2: Product cards appear on the page when a category is mentioned

What this proves: Mentioning a category in the chat turns into real product cards on the page, with photo, name, price and a link to each full product page, filled in from the database rather than from the AI's words. The chat reply stays short because the cards carry the detail.

Check 3: Gift certificates

Screenshot 3: A gift certificate is bought and the code is issued

What this proves: The gift certificate feature works from start to finish: a parent can buy a certificate for a student, a one-time code is issued, and the 10% off promotion is advertised in the banner and on the page. The page also states plainly that this class project takes no payment, so no card details are collected.
